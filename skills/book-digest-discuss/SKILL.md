# Book Digest Discuss — Resume Book Discussion

This skill is a companion to `book-digest`. It loads a previously exported digest file and enters discussion mode.

All user-facing output and interaction must be in **Chinese**. Skill instructions are written in English.

---

## Invocation

```
/book-digest-discuss <file-path>
```

The argument must be a path to a previously exported digest file (`.html` or `.md`) generated by `/book-digest`.

---

## Process

### Step 1: Load Digest File

Read the provided file using the Read tool. If the file does not exist or is not a valid digest file, inform the user:
```
❌ 文件不存在或格式不正确：{file-path}
请提供由 /book-digest 导出的 .html 或 .md 文件路径。
```

### Step 2: Parse Context

Extract from the file:
- Book title (书名)
- Core arguments (论点)
- Key concepts (if present)
- Examples and quotes

This establishes the knowledge base for discussion. You do NOT need to memorize every word — extract enough to answer questions accurately and reference specific sections.

### Step 3: Confirm Entry

Output:
```
📖 已加载《书名》精读文件
来源：{file-path}
已进入讨论模式，可以直接提问。

💬 可以开始提问，例如：
- 「我不理解[概念/论点]」← 深入解析
- 「展开[例子名称]」← 还原更多细节
- 「[概念A]和[概念B]有什么区别」
- 「论点X有什么批评或反驳」
```

### Step 4: Discussion Mode

Handle all subsequent user questions following these rules:

- Answer in Chinese, grounded in the book's content as loaded from the file
- Reference specific arguments, concepts, or examples from the digest
- If the user's question touches a concept not in the digest, expand from the book's perspective (based on AI knowledge)
- If the question goes beyond the book, say so explicitly

**Append-to-file behavior**: After each discussion answer, use **AskUserQuestion** to offer appending:

```
AskUserQuestion(
  questions: [{
    question: "是否将本次讨论内容追加到精读文件中？",
    header: "追加内容",
    multiSelect: false,
    options: [
      { label: "追加", description: "将本次问答追加到文件末尾的「讨论记录」章节" },
      { label: "不需要", description: "跳过，继续讨论" },
      { label: "不再询问", description: "本次会话内后续讨论都不追加，也不再询问" }
    ]
  }]
)
```

If "追加":
- Read the existing file
- Append the Q&A under a `## 讨论记录` section (create the section heading if it doesn't exist yet). Each entry:
  - **HTML**: Insert before `</body>`. If no `讨论记录` section exists, first insert `<h2>讨论记录</h2>`. Then add: `<div class="discussion-entry"><p class="discussion-q">Q: {question}</p><div class="discussion-a">{answer}</div></div>`
  - **Markdown**: Append at end. If no `## 讨论记录` heading exists, first add `## 讨论记录`. Then add: `### Q: {question}` followed by the answer text
- Write the updated file back
- Output: `✅ 已追加至 {filename}`

If "不需要": proceed, ask again on next answer.
If "不再询问": set a session flag, stop asking. End responses with: `💬 还有疑问可以继续问，或输入新书名开始新的精读。`

---

## Quality Rules

- **No fabrication**: Never invent content not in the book. When uncertain, say 「据作者描述…（细节待核实）」
- **Discussion grounding**: Always anchor answers to the book's content. If the question goes beyond the book, say so explicitly.
- **Language**: All output in Chinese. Technical terms and English quotes keep original language.
