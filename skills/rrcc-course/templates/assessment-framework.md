# Growth-Oriented Assessment Framework

## Assessment Philosophy

Rejecting traditional exam-centric education in favor of competency-driven Growth-Oriented Assessment:
- Assessment = competency evidence chain, not score rankings
- Formative assessment as primary, summative assessment as supplementary
- Multiple assessment agents (self-assessment, peer review, instructor evaluation, industry mentor evaluation)

## Assessment Structure

| Assessment Type | Weight | Assessment Method | Assessment Agent |
|----------------|--------|-------------------|-----------------|
| Formative Assessment | {weight}% | Learning portfolio + class participation + reflection journal | Instructor + Self |
| Project Assessment | {weight}% | Project defense + work showcase | Instructor + Peers + Industry Mentor |
| Peer Review | {weight}% | Structured peer review rubric | Peers |
| Growth Record | {weight}% | Competency development portfolio | Self + Instructor |

## Formative Assessment Design

### Learning Portfolio
Collected items:
- [ ] Reflection journal for each unit (using structured reflection tools)
- [ ] Training tool deliverables (canvases, analysis reports, etc.)
- [ ] Milestone project artifacts
- [ ] Peer feedback records
- [ ] Personal growth narrative

### Class Participation Rubric
| Dimension | Excellent | Good | Satisfactory | Needs Improvement |
|-----------|-----------|------|-------------|-------------------|
| Active Participation | Actively contributes, leads discussions | Proactively joins discussions | Passively participates | Does not participate |
| Collaborative Contribution | Drives team progress | Completes assigned tasks | Basic cooperation | Does not cooperate |
| Critical Thinking | Proposes innovative viewpoints | Provides evidence-based analysis | Can express opinions | No viewpoint offered |

## Project Assessment Design

### Project Defense Rubric
| Dimension | Weight | Assessment Criteria |
|-----------|--------|-------------------|
| Problem Definition | {weight}% | Whether the problem originates from real industry needs; clarity of definition |
| Solution Innovation | {weight}% | Whether the solution is innovative; whether course tools are applied |
| Implementation Feasibility | {weight}% | Whether the solution is actionable; whether resource estimation is reasonable |
| Team Collaboration | {weight}% | Whether task division is reasonable; whether collaboration is effective |
| Presentation Quality | {weight}% | Whether logic is clear; whether delivery is persuasive |

## Competency Evidence Chain

```
Class Participation Records -> Training Tool Deliverables -> Reflection Journals -> Project Artifacts -> Defense Performance -> Growth Narrative
```

Each phase produces artifacts that form a complete competency evidence chain, replacing traditional examinations.
