# Bloom's Cognitive Taxonomy -> Training Tool Mapping

## Mapping Rules

During course design, automatically recommend suitable training tools based on the cognitive level of each unit's learning objectives.

## Cognitive Level Mapping

### L1 Remember

**Target Verbs**: Identify, list, recall, retell
**Recommended Tools**: Q&A (问答)(7), Knowledge Base (知识库)(9), Quick Response (抢答)(55), Image Waterfall (图片瀑布流)(6), Survey (问卷)(8)
**Activity Patterns**: Quick assessment, visual memory, competition-based motivation

### L2 Understand

**Target Verbs**: Explain, summarize, compare, classify
**Recommended Tools**: Feynman Technique (费曼学习法)(70), Q&A (问答)(7), ME WE US(24), Knowledge Base (知识库)(9)
**Activity Patterns**: Learning by teaching, peer explanation, concept map construction

### L3 Apply

**Target Verbs**: Execute, implement, use, operate
**Recommended Tools**: SCQA(57), GROW(56), SMART(65), PDCA(61), EOAC(67), Message in a Bottle (漂流瓶)(39), Effective Listening (高效倾听)(71), 30-Second Elevator Pitch (30秒电梯法则)(79)
**Activity Patterns**: Scenario simulation, hands-on tool practice, role-playing

### L4 Analyze

**Target Verbs**: Differentiate, organize, attribute, deconstruct
**Recommended Tools**: SWOT(22), PEST(58), Porter's Five Forces (波特五力)(62), 5 WHY(66), BCG Matrix (波士顿矩阵)(59), Y-Model (Y模型)(69), Systems Thinking (系统思维)(84/85), Iceberg Model (冰山模型)(73), User Persona (用户画像)(10), Empathy Map (共情图)(11), Customer Journey (客户旅程)(30), Pain Points (痛点)(42), Logical Levels Canvas (逻辑层次画布)(34), Question Tree (提问树)(21)
**Activity Patterns**: Case analysis, data analysis, structured decomposition

### L5 Evaluate

**Target Verbs**: Judge, assess, argue, critique
**Recommended Tools**: Structured Reflection (结构化反思)(5), Metacognitive Training (元认知)(33), Timmons (蒂蒙斯)(35), Williams Scale (威廉斯量表)(41), Eugene Raudsepp (尤金·劳德塞)(44), Johari Window (乔哈里视窗)(72), Six Thinking Hats (六顶思考帽)(23), 10/10/10 Rule(68), 360-Degree Leadership (360度领导力)(76), Effectuation (效果推理)(81)
**Activity Patterns**: Peer review, defense evaluation, reflection journals

### L6 Create

**Target Verbs**: Design, build, invent, generate
**Recommended Tools**: TRIZ(14), Design Thinking (设计思维)(80), Brainstorming (头脑风暴)(9/37), Osborn's Checklist (奥斯本)(28), Innovation Combination (创新组合)(19), Analogical Innovation (类比创新)(20), Remote Association (远距离联想)(29), Synectics Analogy (综摄法类比)(32), Random Stimulus Divergence (随机刺激发散)(46), Business Model Canvas (商业画布)(13), Value Proposition (价值主张)(12), MVP(63), Hero's Journey (英雄之旅)(74), Story Thinking (故事思维)(83), Product Innovation (产品创新)(88), Model Innovation (模式创新)(87), Efficiency Innovation (效率创新)(86), Six-Position Product Innovation Canvas (六位产品创新画布)(27)
**Activity Patterns**: Prototype design, solution creation, project-based practice

## Triple Integration Direction Mapping

### Ideological-Political Integration (思政融通)

**Core Tools**: Structured Reflection (结构化反思)(5), ME WE US(24), Personal Value Realization (个人价值实现)(26), Metacognitive Training (元认知)(33), Iceberg Model (冰山模型)(73), Hero's Journey (英雄之旅)(74), Johari Window (乔哈里视窗)(72), Logical Levels Canvas (逻辑层次画布)(34), Circle of Competence (能力圈)(77)
**Design Principle**: Naturally extract values-oriented elements from professional content, and achieve internalization through reflection and self-awareness tools

### Innovation & Entrepreneurship Integration (融双创)

**Core Tools**: Business Model Canvas (商业画布)(13), Value Proposition (价值主张)(12), TRIZ(14), MVP(63), AARRR(64), Timmons (蒂蒙斯)(35), Design Thinking (设计思维)(80), Product Innovation (产品创新)(88), Model Innovation (模式创新)(87), Efficiency Innovation (效率创新)(86), Six-Position Product Innovation Canvas (六位产品创新画布)(27), Viral Spread Canvas (病毒传播画布)(31), Effectuation (效果推理)(81)
**Design Principle**: Driven by real entrepreneurial scenarios, covering the complete innovation chain from problem discovery to solution validation

### Industry Integration (融产业)

**Core Tools**: User Persona (用户画像)(10), Empathy Map (共情图)(11), Customer Journey (客户旅程)(30), Pain Points (痛点)(42), SWOT(22), PEST(58), Porter's Five Forces (波特五力)(62), STP(36), Resource Inventory (资源清单)(38), McKinsey 7-Step Method (麦肯锡七步法)(60), Y-Model (Y模型)(69)
**Design Principle**: Introduce real enterprise problems (obtain latest cases through web search), and solve practical problems using industry analysis tools
